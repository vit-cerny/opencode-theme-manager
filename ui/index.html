opencode's TUI has no font or geometry settings of its own: these apply to your terminal profile and to the preview. The generated preview.css carries them for the desktop/web surface.
6 · Layout & tabs (cli.json)
These are real opencode CLI settings, written to cli.json with a backup.
7 · Desktop app (GUI)
checking for the opencode desktop app...
The desktop GUI is a Chromium shell with its own 36 bundled themes and no config file: the only levers are localStorage keys its preload reads (opencode-theme-id, opencode-theme-css-dark/light). Driving them needs a DevTools port, so the app has to be restarted once with --remote-debugging-port=9222 - that is what Restart app with theming does. Terminal version: node tools/desktop-apply.mjs --glass --restart
