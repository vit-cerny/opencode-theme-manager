## Bottom line for the theme manager

- CLI/TUI: restyle ONLY via theme JSON files (global + project dirs) + `cli.json` layout keys. No font/size/geometry/CSS/opacity key exists — font, size, opacity, acrylic belong to Windows Terminal (`settings.json` above), not opencode.
- Desktop/web client: no file-based CSS hook; appearance = in-app settings persisted to `localStorage` (`opencode-theme-id`, `opencode-color-scheme`, `opencode-theme-css-light/dark`) consumed by `/oc-theme-preload.js`. A manager can at most drive the app's own settings or (unsupported) seed `localStorage` in its Chromium profile — no documented path.
- Token contract: 60 required `base` entries (`docs/v2-base-tokens.json`); states optional; hue per-mode with 3 mandatory semantic hues.
